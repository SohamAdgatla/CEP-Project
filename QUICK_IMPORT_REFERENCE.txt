================================================================================
HOW TO USE
================================================================================

METHOD 1: Import Everything (Simplest)
----------------------------------------
from all_modules import *

# Now use directly:
frame = cv2.imread('image.jpg')
model = YOLO('yolov8n.pt')
result = np.array([1, 2, 3])


METHOD 2: Import as Module (Recommended)
-----------------------------------------
import all_modules as mod

# Use with prefix:
frame = mod.cv2.imread('image.jpg')
model = mod.YOLO('yolov8n.pt')
result = mod.np.array([1, 2, 3])


METHOD 3: Specific Imports (Best Practice)
--------------------------------------------
from all_modules import cv2, np, YOLO, Path, time, os

# Use directly:
frame = cv2.imread('image.jpg')
model = YOLO('yolov8n.pt')

Example 1: Detection Script

cap = cv2.VideoCapture(0)

    results = model(frame)

    if cv2.waitKey(1) & 0xFF == ord('q'):

================================================================================
ADDING NEW MODULES
================================================================================

When you add a new module to the project:

1. Add to all_modules.py in the appropriate section:
   
   try:
       import new_module
   except ImportError:
       new_module = None
       print("Warning: new_module not installed")

2. Add to __all__ list at the bottom of all_modules.py

3. Update requirements.txt if it's a new dependency
